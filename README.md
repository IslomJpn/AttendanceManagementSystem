# Attendance Management System

Professional attendance management system developed with ASP.NET Core MVC.

## Features

- Employee Login
- Admin Login
- Attendance Management
- Clock In / Clock Out
- Attendance History
- Paid Leave Management
- Attendance Correction Request
- Employee Management
- Monthly Attendance Summary

## Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- HTML
- CSS
- JavaScript
